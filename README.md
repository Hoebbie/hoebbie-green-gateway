# Hoebbie Gateway releases

This repository contains reviewed installation files for the Home Assistant
app. Development history, personal documentation, configuration values and
credentials are not distributed here. Existing installations keep the same
repository URL and app slug. Credentials are supplied locally at runtime.
Stable protocol identifiers remain unchanged for compatibility.

Install through the Home Assistant app store using this repository URL.
The gateway establishes outbound authenticated connections; it exposes no
inbound app port. Access to an authorized backend is required.
